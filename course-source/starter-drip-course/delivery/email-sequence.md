# 📬 Email Drip Sequence — 30 Days

Set up once on any email tool (MailerLite, ConvertKit, Amazon SES, or even a Gmail
mail-merge). One email per day, same time each morning (8 AM works). Each email: hook →
what today's lesson covers → one-line action nudge → pointer to the course pack.

Two delivery options for the pack itself:
1. **Attach/link the full pack (PDF + HTML ebook)** on Day 1 — students read Day N in the ebook.
2. **Per-level unlock** — send Level 1 PDF on Day 1, Level 2 on Day 9, etc. (higher perceived value, slightly more setup).
