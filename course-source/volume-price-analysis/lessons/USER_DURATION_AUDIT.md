## Counting method

- **Main narration words:** the text under `Full narration script`, including the new worked-example passages added during this pass.
- **Extended case words:** the separate `Extended spoken case analysis — additional narration` section, when present.
- **Chart walkthrough words:** the lesson-specific segment in `CHART_WALKTHROUGHS.md`. These notes are supplemental; count them as spoken only when they are actually delivered.
- **Spoken total:** main narration + extended case + chart walkthrough.
- **140 / 125 words per minute:** illustrative estimates only. Real delivery includes natural pauses, emphasis, pointing at charts and explaining a diagram. If a walkthrough is performed silently or is not used, the total must be recalculated for the actual delivery.
- **Active practice to reach 12 minutes:** a planning estimate at 140 wpm, rounded up to half-minute increments. It is not evidence that an activity already takes that long.
- Meaningful active time includes inspecting a chart, marking a level, comparing examples, writing a conditional scenario, revealing and reviewing an outcome, or completing the knowledge check. Do not count loading time, idle waiting or padding as teaching.

## What this means for production

1. **Modules 2–6:** the manuscript pass now has enough spoken substance to make a 12–16 minute lesson plausible when paired with the required practice. Lessons with the shortest spoken estimates should get a meaningful comparison or apply task, with time reserved for the learner to respond and review feedback.
2. **Module 1:** deliberately left untouched in this pass. The figures above are source counts only; the module is not being reopened for content editing now. The full end-to-end duration still needs to be measured during the later timed rehearsal.
3. **No lesson is marked runtime-verified.** The course outline's target duration does not prove how long a real learner takes.
4. **Do not add filler to meet the clock.** Add a worked example, a contrasting case, a reasoned counterexample, a chart annotation task or meaningful feedback where a lesson needs more time.

## Final duration acceptance process

For each of the 30 lessons:

1. Deliver the main narration and whichever chart walkthrough content is part of the actual lesson at a natural, beginner-friendly pace.
2. Complete the three learner stages: **Level 1 — Notice, Level 2 — Compare, Level 3 — Apply**. Time actual observation, comparison, written reasoning, staged reveals and response review.
3. Include model reasoning and the knowledge check. Giving the learner an answer to look at is not the same as providing time to attempt and review the task.
4. Run the full lesson from start to finish and record elapsed time. Exclude technical delays; include purposeful learner activity.
5. Pilot with a genuine beginner and note whether the instructions, chart labels and model reasoning make sense without coaching.

**Approval threshold:** the measured learner experience must be **more than 10:00 minutes**, not simply labelled as a 10-minute lesson. Aim for **12–16 minutes** normally. No lesson should be marked verified until a full timed run and beginner check have been completed.
