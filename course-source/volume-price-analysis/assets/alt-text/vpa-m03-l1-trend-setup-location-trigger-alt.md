# Accessible description — 3.1: Finding a Setup Inside an Established Trend

**Teaching focus:** A setup area is only a place to watch. It is not an entry until a defined trigger appears and invalidation is clear.

## Panel A — Location is defined
The pullback approaches an area linked to earlier structure. Mark the area before choosing an entry trigger.

## Panel B — Trigger appears
Price holds the area and reclaims a nearby minor swing. Check that invalidation still fits the structure.

## Panel C — Setup invalidates
Price breaks the swing that justified continuation. A broader uptrend label cannot rescue this setup.

**Visual key:** Green/red candle bodies indicate close above/below open. Neutral grey columns show recorded activity. The final bar is highlighted; the dashed comparison line is the average of the ten preceding bars. Gold reference line marks the labelled area. Neither colour nor reference guarantees future direction.

**Data:** Constructed practice series. The linked CSV preserves row-level OHLCV values and the activity baseline. Mobile charts stack the cases with larger text.
