# Accessible description — 3.2: Is the Pullback Running Out of Steam?

**Teaching focus:** Compare pullback depth, speed, activity and structure before deciding whether continuation remains plausible.

## Panel A — Shallow pullback
The counter-move is shallow; key structure remains intact. Wait for a defined trigger before considering continuation.

## Panel B — Deep pullback
Price moves through the swing that supported the trend. The original continuation premise is weakened.

## Panel C — Reclaim supports view
Price reclaims a local swing after the pullback holds. What new price evidence supports the view?

**Visual key:** Green/red candle bodies indicate close above/below open. Neutral grey columns show recorded activity. The final bar is highlighted; the dashed comparison line is the average of the ten preceding bars. Gold reference line marks the labelled area. Neither colour nor reference guarantees future direction.

**Data:** Constructed practice series. The linked CSV preserves row-level OHLCV values and the activity baseline. Mobile charts stack the cases with larger text.
