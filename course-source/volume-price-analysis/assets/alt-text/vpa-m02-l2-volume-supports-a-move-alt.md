# Accessible description — 2.2: When Volume Supports a Move

**Teaching focus:** A breakout needs a defined boundary, a suitable activity baseline and follow-through. High volume alone is not confirmation.

### Panel A — Break holds
Price closes beyond the boundary and builds progress. What evidence shows acceptance beyond the range?

### Panel B — High activity, return inside
The outside move is not retained; price returns into the range. Which later bar changed the reading?

### Panel C — Retest then progress
A pullback holds the old boundary before price advances. What would invalidate continuation?

**Visual key:** Green/red candle bodies indicate close above/below open. Neutral grey columns show recorded activity. The highlighted final bar is the case under review; its dashed comparison line represents the average of the ten preceding bars. Gold reference line marks the labelled area. Read the panel's observation and next question independently; the reference is not a guarantee of reversal or continuation.
