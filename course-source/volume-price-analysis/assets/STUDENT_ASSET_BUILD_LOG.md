## What is included

Every lesson has its own linked primary chart and independent ChartLab. The student can inspect the actual chart rather than having to infer or imagine price from a written prompt. Each asset package includes:

- **Primary SVG chart:** labelled price candles/wicks, matching time-based volume, and relevant price zone or profile references.
- **Interactive ChartLab HTML:** Notice → Compare → Apply practice, lesson-specific prompts, model explanations and contrasting outcomes revealed after the initial reading.
- **CSV source data:** OHLCV rows for the base chart and staged/alternate outcomes; Volume Profile lessons also include profile-bin values and reference levels.
- **Accessible description:** chart summary, alt text, data scope and interpretation limits.

Volume Profile lessons use a horizontal histogram aligned to price alongside the candles and time-based volume. Plan-construction lessons show relevant zones and, where appropriate, labelled trigger/invalidation/objective levels. Examples are synthetic, not historical market data or trade recommendations.

## Student-facing figure convention

Primary lesson figures are numbered by module and lesson: Figure 1.1–1.5, Figure 2.1–2.5, continuing through Figure 6.1–6.5. Related ChartLab panels use letter suffixes (a–e). The lesson manuscripts reference the corresponding numbered figure. Internal planning stages are not shown as student-facing “Level 1/2/3” or “easy/guided/independent” labels; the student interface uses natural task headings. Repeated “synthetic data” banners have been removed from the figures. Illustrative/provenance disclosure remains in accompanying lesson/source/alt-text notes, while the CSV records preserve data provenance.

## Quality and limits

The standalone lessons use actual embedded SVG charts, not prompts that require a learner to imagine the price sequence. They show written tasks and feedback alongside the visual, but written-response fields only enforce completion length; they do not semantically grade free-text reasoning.

The source assets have been created and committed. **This is not a claim that browser rendering, responsive behaviour, keyboard access, screen-reader output, 200% zoom, lesson duration or novice comprehension have passed.** Those checks must be run against the exact rendered experience before the package is approved for public release.

## File layout

- `chartlabs/`: independent student-facing practice pages.
- `student-assets/svg/`: primary chart visuals.
- `student-assets/data/`: synthetic OHLCV/profile source data.
- `student-assets/alt-text/`: accessibility descriptions and limitations.

No member-area integration, website deployment or merge into `main` is included in this checkpoint.
