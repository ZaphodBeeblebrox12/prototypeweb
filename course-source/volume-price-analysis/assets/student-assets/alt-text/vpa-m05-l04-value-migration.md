# Accessibility and source notes — M05-L04

**Lesson:** When the Market's Focus Shifts: Reading Changes in Value
**Purpose:** Compare similarly constructed profiles and check whether profile migration is supported by current price structure.
**Data:** Synthetic OHLCV and profile bins. Not historical data, forecast or recommendation.

## Description
The first profile is concentrated lower, while a later comparable profile is centred higher. Price advances as the new area develops. The alternative outcome returns into earlier value, showing that profile migration is not an automatic forecast.

The right-hand panel shows activity allocated to price bins for the explicitly named period. POC identifies the highest-volume row; VAH/VAL mark the selected value area. The left-hand panel shows candle price behaviour and matching time-based volume. The profile is historical context and current price behaviour must be assessed separately.
