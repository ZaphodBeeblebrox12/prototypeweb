# Accessibility and source notes — M03-L04

**Figure number:** Figure 3.4; interactive panels use Figure 3.4a–Figure 3.4e.
**Lesson:** Finding Opportunities at the Edges of a Trading Range
**Purpose:** Distinguish range rotation from a sustained breakout using boundary interaction and follow-through.
**Data:** Synthetic OHLCV created for instruction, not historical prices or a signal.

## Chart description
Price rotates around the marked upper edge of a range and makes an excursion above it. The latest focus event is above the old boundary, but whether price can hold outside depends on the next bars.

Candlestick price bars appear above the volume bars for the same intervals. Green indicates close above open; red indicates close below open. The dashed line is the recent-bar volume average. The marked zone is Range high, a context marker, not a guarantee.
