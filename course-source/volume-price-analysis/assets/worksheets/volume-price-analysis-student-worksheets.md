# Read Volume. Find Trade Setups.
## Student worksheets and worked examples

These worksheets turn the course's chart-reading process into a repeatable practice. They are for learning and review; they do not create trading signals or recommendations. Use the linked lesson chart and its synthetic-data note before completing each sheet.

| Field | Your notes |
|---|---|
| Instrument / timeframe / data source | |
| Market state (trend, range, transition or unclear) | |
| Structure and key zone(s)—why they matter | |
| Recent price/volume event and baseline | |
| Important uncertainty / data limitation | |
| Scenario A and its confirming condition | |
| Scenario B and its confirming condition | |
| What would make you wait / take no trade? | |

### Worked example — synthetic 200–208 range
| Field | Example note |
|---|---|
| Market state | Price has rotated between approximately 200 and 208 over two sessions. |
| Location | Near the upper boundary, 208. The zone is justified by repeated prior turns. |
| Recent event | Price traded above 208 but closed at 207.4, inside the range; recorded activity was elevated against the stated local baseline. |
| Uncertainty | One bar does not establish a sustained breakout or a reversal. |
| Scenario A | A close above 208, successful retest and further progress support continuation. |
| Scenario B | A sustained return inside and failed reclaim support a range-return reading. |
| No-trade | Price overlaps around 207–209 without a trigger: wait. |

**Good standard:** Every level has a reason. “Bullish” or “bearish” by itself is not a context note.

## 2. Evidence sheet
**Use with:** [Module 6.2 — Read the Evidence](../../lessons/MODULE_06_COMPLETE_TRADE_PLAN.md)

### Blank template
| Field | Your notes |
|---|---|
| What price did (open/high/low/close, range, close location) | |
| Location: where did it happen? | |
| Recorded volume and the comparison baseline | |
| What is directly observable? | |
| Primary interpretation (clearly labelled as a hypothesis) | |
| Alternative explanation | |
| What future event would favour the primary reading? | |
| What would weaken it? | |

### Worked example — synthetic breakout attempt
**Observation:** Price traded above 56.5 but closed at 55.8, back inside the prior range. Recorded volume was 1.8× the average of the previous ten comparable bars. The broader swing structure remains upward.

**Primary interpretation:** The attempt to hold above the range may have failed.

**Alternative:** Price may be temporarily balanced before another attempt.

**Discriminator:** A later hold above the boundary supports continuation; a return inside followed by a failed reclaim weakens it.

**Good standard:** A fact is not the same as the explanation. Do not write “large sellers absorbed the breakout” as an observable fact.

## 3. Two-scenario thesis canvas
**Use with:** [Module 6.3 — Build Your Trade Scenario](../../lessons/MODULE_06_COMPLETE_TRADE_PLAN.md)

### Blank template
| Question | Scenario A | Scenario B |
|---|---|---|
| What must happen? (observable condition) | | |
| Why does that evidence matter at this location? | | |
| What additional evidence is needed? | | |
| What would weaken or invalidate this scenario? | | |
| If neither scenario activates, what will I do? | | |

**No-trade / wait condition:**  
_Write this explicitly. Do not force a choice while price remains unresolved._

### Worked example — range high near 208
| Question | Continuation | Return to range |
|---|---|---|
| Trigger | Close above 208, then hold on a retest and make progress. | Return below 208 and fail to reclaim it. |
| Why it matters | Price sustains activity beyond the prior boundary. | The outside excursion was not retained. |
| Weakens the idea | A sustained return inside and failed reclaim. | A sustained hold above 208 and further progress. |
| No trade | Both paths remain plausible and no trigger occurs. | Both paths remain plausible and no trigger occurs. |

**Good standard:** Both scenarios are testable and neither depends on guessing participants' hidden motives.

## 4. Pre-trade ticket
**Use with:** [Module 6.4 — Plan the Trade Before You Take It](../../lessons/MODULE_06_COMPLETE_TRADE_PLAN.md)

### Blank template
| Field | Your plan |
|---|---|
| Thesis and chart evidence | |
| Entry trigger (exact, observable condition) | |
| Intended entry / order approach | |
| Thesis invalidation condition | |
| Stop placement and reason | |
| Instrument value / contract or unit assumptions | |
| Position-size calculation under my own risk rules | |
| Estimated costs, spread and slippage | |
| Objective and structural reason | |
| Management / exit rules | |
| No-trade condition | |

### Worked example — risk arithmetic only
Assume a **hypothetical** entry at 54.5, stop at 51.5 and contract value of 2 currency units per price unit. The price difference is 3.0, so the estimated price risk is (3.0\times2=6) currency units per unit before fees, slippage and other instrument-specific effects.

That arithmetic does **not** approve a trade. The trigger must actually occur, the stop must make sense relative to the thesis, the potential objective must be plausible, and the final position size must follow the learner's own predefined risk rules. If the plan does not fit, pass rather than distorting the chart.

<a id="capstone-review"></a>
## 5. Capstone review
**Use with:** [Module 6.5 — The Complete Walkthrough](../../lessons/MODULE_06_COMPLETE_TRADE_PLAN.md)

### Before revealing later bars
- [ ] I wrote the market state and explained the important zone(s).
- [ ] I recorded at least two observations without adding a cause.
- [ ] I named the volume feed/baseline or noted the limitation.
- [ ] I wrote two competing scenarios before seeing the outcome.
- [ ] Each scenario has a trigger, a weakening condition and a no-trade state.
- [ ] I did not claim that a candle reveals participant identity or intent.

### After revealing later bars
| Review question | Your notes |
|---|---|
| What new evidence appeared? | |
| Which scenario gained support, and why? | |
| Which scenario weakened, and why? | |
| Did I update the interpretation without rewriting the initial observations? | |
| Could a trade be constructed under my own risk rules? Why / why not? | |
| What did I learn about the process, regardless of outcome? | |

### Worked review standard
A good review evaluates the reasoning and execution available at decision time, not only the final profit/loss. A valid plan can lose. A disciplined no-trade can miss a later favourable move without making the original decision a mistake. Explain which observable facts and rules support your conclusion.
