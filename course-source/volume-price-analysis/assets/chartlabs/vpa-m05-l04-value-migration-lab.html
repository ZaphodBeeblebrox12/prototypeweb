When the Market's Focus Shifts: Reading Changes in Value

A later profile can be centred higher or lower. That records a shift in where activity occurred; whether the shift persists is a separate question.

Before you begin: these are actual synthetic price candles, time-based volume bars and a horizontal volume-at-price profile. Every profile window is labelled. A shift in profile is a change in the selected activity distribution, not a guaranteed forecast.
