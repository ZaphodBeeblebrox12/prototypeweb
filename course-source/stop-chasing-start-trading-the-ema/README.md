# Stop Chasing. Start Trading the EMA.

**Status:** Prepared for Course Builder staging as an editable draft. It is not published and is not approved for public release.

## Course intent

This is an approximately 50-minute, two-module strategy course for traders who already know what EMAs are and how to add them to a chart. It focuses on market qualification, actionable EMA setups, no-trade conditions, late entries, invalidation, loss control and a practical playbook.

It is not an EMA calculation or moving-average introduction course. The earlier four-module foundations manuscript remains archived separately and is not part of this import.

## Structure

- Module 1 — Find Trades Worth Taking (4 lessons)
- Module 2 — Stay Out and Avoid Failure (4 lessons)
- Total planned lesson time: 50 minutes. This is an editorial estimate, not measured learner completion time.
- All eight lessons use release day 1; the course is not drip-locked.
