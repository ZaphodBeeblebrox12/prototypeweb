# ✅ PRE-TRADE CHECKLIST — print and tape to your monitor

```
□ 1. HTF BIAS      Daily trend clear? Trading WITH it?
□ 2. LEVEL         Entry at a real zone (3–5 zones max on chart)?
□ 3. CONFLUENCE    2+ independent tools agree here?
□ 4. TRIGGER       Defined trigger (pattern candle / placed limit)?
□ 5. STOP          Beyond structure + buffer — NOT inside noise?
□ 6. SIZE          Formula-calculated? Reverse check: loss ≤ budget?
□ 7. TARGET        Defined BEFORE entry? Expected R:R ≥ 2?
□ 8. EXPECTANCY    This setup type is positive in my journal/backtest?
□ 9. DAILY LIMIT   Within 3-loss / −3% circuit breaker today?
□ 10. ONE-LINER    Can I say this trade in one sentence? If not — NO TRADE.
```

**Post-trade (2 min):** R result · setup type · checklist Y/N · mistake code · one line.
