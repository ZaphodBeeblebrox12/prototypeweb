# ChartLab Answer Keys — Review Draft

- `ANSWER-KEYS.md`: human-readable teaching key with rationale, feedback variants, acceptable alternatives and knowledge checks.
- `answer-keys.json`: structured version for a future implementation, including reference bands and coaching ranges.

The values are tied to the current standalone prototype's illustrative chart data. They must be revalidated if the candle dataset or chart price mapping changes. These values are coaching references, not strict or universal grading thresholds.

No repository files are included or changed by this package.
