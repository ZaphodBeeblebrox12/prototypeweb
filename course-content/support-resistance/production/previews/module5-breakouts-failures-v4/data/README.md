# Historical OHLC extracts

These CSV files contain the exact daily Open/High/Low/Close rows used by the chart preview:

- `NIFTY50-2016-breakout-failure.csv` — July–October 2016; Lesson 12 staged breakout attempt and later return below the candidate band.
- `NIFTY50-2014-retest-hold.csv` — June–September 2014; Lesson 13 return towards a former-resistance area and later price staying above it in the selected window.
- `NIFTY50-2018-failed-breakout.csv` — December 2017–March 2018; Lesson 14 move beyond a prior upper area followed by a return and failed continuation.

Source: `NIFTY 50.csv` from https://github.com/VatsalSin/Stock-Market-Indices-Dataset/blob/main/NIFTY%2050.csv. The extracts exclude volume so this module's historical chart exercises isolate price behaviour; volume is discussed conceptually but is not tested by these chart examples.
