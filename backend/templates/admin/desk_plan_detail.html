How checkout resolves a price

For the requested country and billing interval, checkout checks an active country-specific GeoPlanPrice first. If none matches, it checks the active region override with a null country. It then falls back to the active global PlanPrice. A missing matching record is not a zero-price sale; checkout reports that no active price exists.

This page lists stored configuration only. It does not infer a visitor country, execute checkout resolution, or certify a provider price as tested.

Administration boundary

This page does not edit Products, Plans, prices, feature bullets, trial settings or community mappings. Historical PaymentIntent and Subscription price snapshots are not changed by future catalogue edits. Use the existing Advanced Administration workflow for configuration changes.
